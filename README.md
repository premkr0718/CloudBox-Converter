# ☁️ CloudBox Converter

A browser-based file conversion tool built using HTML, CSS and JavaScript. CloudBox Converter allows users to convert images into different formats and create PDF and DOCX documents.

## 🚀 Features

- Upload multiple images.
- Convert images between JPG, PNG and WebP formats.
- Convert images into PDF.
- Create DOCX documents containing images.
- Simple and user-friendly interface.
- File size validation.
- Download converted files.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Amazon S3
- AWS Lambda
- Amazon API Gateway

## ▶️ How to Run

1. Download or clone this repository.
2. Keep all three project files in the same folder.
3. Open `Project.html` in your web browser.
4. Select images and choose your desired output format.
5. Convert and download your files.

## ☁️ AWS Integration

The project is designed to use AWS services:

- **Amazon S3:** Cloud storage for converted files.
- **AWS Lambda:** Serverless backend processing.
- **Amazon API Gateway:** Connects the frontend to the backend.

*Note: Cloud upload functionality depends on the configured AWS backend.*
